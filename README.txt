
우리반 작품 갤러리 실행 방법

1. 압축을 풉니다.
2. Python이 설치되어 있어야 합니다.
3. 처음 한 번만 이 폴더에서 터미널을 열고 아래 명령을 실행합니다.

   pip install -r requirements.txt

4. 그 다음부터는 "실행하기.bat"를 더블클릭하면 됩니다.

주요 기능
- 이름만 입력해서 입장
- 작품 등록
- 대표 사진 / 상세 사진 여러 장 업로드
- 작품 상세 페이지
- 학생별 포트폴리오
- 카테고리 필터
- 네이버 블로그 링크 연결
- 본인 작품 삭제

주의
- gallery.db에는 게시글 정보가 저장됩니다.
- uploads 폴더에는 업로드한 사진이 저장됩니다.
- 두 항목을 삭제하면 등록한 작품이 사라질 수 있습니다.
